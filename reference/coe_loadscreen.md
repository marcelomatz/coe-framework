# coe_loadscreen — referência da API

> Gerado de `coe_loadscreen/types.lua` por `tools/gen_reference.lua`. Não edite à mão.

Todos os exports são client-side.

## Exports

### `IsActive()`

Informa se a tela de carregamento ainda está ativa no cliente.

**Retorno**

- `boolean` `isActive` — Retorna `true` se a tela de carregamento ainda estiver ativa

### `Shutdown()`

Fecha imediatamente a tela de carregamento manual no cliente.
