# coe_characters — referência da API

> Gerado de `coe_characters/types.lua` por `tools/gen_reference.lua`. Não edite à mão.

Todos os exports são client-side.

## Exports

### `IsOpen()`

Verifica se a interface de seleção de personagem está aberta no cliente.

**Retorno**

- `boolean` `isOpen` — Retorna `true` se a seleção estiver aberta.

### `CloseSelection()`

Fecha a interface de seleção de personagem e destrói a cena 3D atual.
